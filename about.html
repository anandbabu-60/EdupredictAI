About EduPredict AI

An AI-powered academic decision support system designed to identify learning vulnerabilities early and improve institutional graduation outcomes.

What is EduPredict AI?

EduPredict AI is a production-grade machine learning web application engineered for undergraduate computer science and higher education environments. It processes continuous assessment data, attendance rates, study habits, and demographic factors to predict expected student performance and categorize students into proactive support tiers.

Unlike traditional static grading portals that only report past performance after exams are over, EduPredict AI acts proactively midway through the semester, empowering faculty advisors to structure timely remedial tutoring and guidance.

End-to-End Machine Learning Pipeline

The system follows an industry-standard Machine Learning lifecycle from raw dataset ingestion through feature engineering, hyperparameter tuning, model serializing, and REST API deployment:

1
Dataset Acquisition & Ingestion Historical academic records comprising attendance, internal marks, previous scores, and study time from institutional repositories.
2
Data Cleaning & Preprocessing Handling missing values, outlier detection using IQR, One-Hot Encoding for categorical features, and Standard Scaling for numeric vectors.
3
Feature Selection & Importance Correlation heatmaps and Random Forest feature importance algorithms determine that Attendance and Previous Scores carry the highest predictive variance.
4
Model Training & Hyperparameter Tuning Comparing Multiple Linear Regression, Ridge, Support Vector Regression (SVR), and Random Forest Regressors using 5-Fold Cross Validation.
5
Model Evaluation & Serialization Evaluated via Mean Absolute Error (MAE), RMSE, and R² Score. The top-performing pipeline is saved into binary format using `joblib.dump()`.
6
Flask REST API & Web Application Flask microservices expose `POST /api/predict`, receiving JSON payloads, executing ML inference in real-time, and returning predictions with confidence intervals.

Technical Viva Highlights

  • Why ML over hard-coded rules? Machine learning learns non-linear interactions between multiple concurrent factors (e.g. high study time compensating for lower prior scores) that fixed if-else rules cannot model.
  • Decoupled Architecture: Frontend uses standard REST JSON protocols, allowing independent deployment of the user interface on static CDNs while Flask models scale on container runtimes.
  • Ethical AI Guardrails: System provides transparent educational recommendations without making high-stakes, punitive, or medical claims.
